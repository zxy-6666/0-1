# MPC 工作产物仓库

先进封测半导体工厂 MPC（生产排程调度）工程师的个人工作仓库，用于存放日常工作产物。

## 目录结构

| 目录 | 用途 |
|------|------|
| `reports/` | 报表成品（日报/周报/月报、帆软报表、数据分析报告等） |
| `scripts/` | 小程序/脚本（排程辅助工具、数据处理脚本等） |
| `sql/` | SQL 脚本（查询、报表取数等） |
| `data/` | 数据文件（仅放脱敏/模拟数据，禁止上传含敏感信息的生产数据） |

## 使用约定

- 生产数据必须先脱敏（隐藏工号、批号、设备号、产能等敏感字段）再存入 `data/`
- 报表建议同时保留源数据文件和成品文件
