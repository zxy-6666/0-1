# 文件分类说明

> 目的：一眼分清根目录下哪些是**数据文件**、哪些是**源码文件**、哪些是**工具/缓存/运行产物**。
> 原则：**源码与数据分开，运行生成的产物可随时删除（程序会自动重建）。**

---

## 一、按用途分类总览

| 类别 | 位置 | 说明 | 能否删除 |
|---|---|---|---|
| 🔷 **数据文件** | `data/` | 排程输入配置表（CSV + json），是"生产资料"，最重要 | ❌ 不能删 |
| 💾 **核心源码** | 根目录 `*.py` + `web/` | 系统主体，`py app.py` 运行的就是这些 | ❌ 不能删 |
| 🛠 **工具脚本** | `tools/` | 开发/测试辅助脚本（压力测试、pin 回归、命令行排程） | ⚠️ 可选删 |
| 📦 **打包工具** | `Windows打包/` | 生成可执行文件的工具与说明 | ⚠️ 需要发布 exe 才留 |
| 📜 **文档** | `SOP_使用说明.md/.docx` | 使用说明（SOP） | ❌ 建议保留 |
| 🗑 **运行缓存** | `__pycache__/`、`*.pyc` | Python 自动生成的字节码缓存 | ✅ 可删（自动重建） |
| 🖼 **输出产物** | `output/`、`static/` | 排程结果快照/甘特图/Excel（运行生成） | ✅ 可删（自动重建） |

## 三、运行后会自动"回来"的目录

这些目录/文件**由程序运行自动重建**，删掉也没关系，但会随每次运行重新出现：

- `__pycache__/`、`*.pyc` —— Python 缓存
- `output/snapshots/`、`output/*.xlsx`、`output/*.png` —— 排程结果
- `static/*.png` —— 甘特图
- `output/.mplcache/` —— matplotlib 缓存

> 每次用网页"生成排程"后，以上都会出现。嫌乱的话定期删 `output/`、`static/`、`__pycache__` 即可。

## 四、打包 vs 源码：目录差异

| 项目 | 源码运行 | 打包后(exe) |
|---|---|---|
| 程序入口 | `web/` 下 `py app.py` | 双击 `schedule_app.exe` |
| 数据目录 | `data/`（项目根） | exe 旁边的 `data/` |
| 输出目录 | `output/`（项目根） | exe 旁边的 `output/` |
| 源码文件 | 根目录 `*.py` | 已打进 exe，不需要 |
| Windows打包 | `Windows打包/src/` 是打包用的源码副本 | — |

---

## 五、需要定期备份的

**只有 `data/` 需要备份**（它是所有排程的输入）。`output/` 是结果可再生成，源码在源码包/打包工具里。

```
data/            ← 必须备份（配置表就是"生产资料"）
SOP_使用说明.*   ← 建议保留（操作手册）
```
